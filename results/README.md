# 实验结果目录规则

- `raw/`：模型原始响应、请求元数据和浏览器轨迹；默认忽略，不得含 API Key；
- `private/`：盲法 sample→run/method 映射、原始/仲裁标签、评分合并数据、参与者映射、联系方式及未去标识录音/日志；始终本地受控保存；
- `drafts/`：冻结前 pilot 与临时 manifest；不进入论文主结果；
- 正式去标识 manifest、最终评分、统计表和绘图数据可在人工复核后放在本目录根部，并记录对应 Git tag 与 SHA-256。

正式 runner 必须写入一个全新空目录。不得把 `/tmp`、Mock、示例数据或工程回归日志复制为正式结果。标注包与私有方法映射必须分离；合并评分数据不得在分析冻结前交给标注者。任何公开数据都要先经过隐私检查和论文协议中的排除规则审计。
