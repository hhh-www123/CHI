# 论文研究协议（冻结前草案）

状态：`draft-unfrozen`
版本：0.2（2026-11-03）

本文件规定论文实验在看见正式结果前必须固定的主张、条件、终点与分析规则。只有完成第 12 节的冻结检查并记录任务、Prompt、模型与代码哈希后，产生的数据才可标记为正式实验；Mock、开发联调和冻结前试跑均不得进入主结果表。

## 1. 暂定论文定位

暂定题目：**Maintaining Intent over Time: Mitigating Long-Horizon Distortion in Agentic Generative Interfaces**。

研究对象是连续自然语言编辑中的结构化生成式界面。本文把“长程失真”限定为：随着交互轮次和目标年龄增长，系统偏离仍有效的用户目标、授权边界、持久约束、版本指代或稳定 UI 状态。本文不评价真实旅行质量，也不把单一旅游原型外推为全部 GenUI。

预期贡献：

1. 一套区分目标遗忘、旧目标泄漏、越权状态变化、版本错误和 UI 结构漂移的长程失真操作化框架；
2. 一种局部 Patch、持久锁与不变量、乐观版本、候选预览和显式提交组合的防失真方法；
3. A–D 自动对照与 C–D 被试内研究，量化保真、恢复、选择成本和感知控制之间的权衡。

## 2. 研究问题与预注册假设

- **RQ1**：方法 D 是否比整页生成、Prompt 保持和单纯路径白名单更少产生未授权持久变化？
- **RQ2**：目标距离增长时，不同方法的目标保持率如何衰减？
- **RQ3**：显式锁、版本与候选确认是否改善错误恢复和正确遗忘？
- **RQ4**：完整方法是否提高用户感知控制和适当依赖，代价是否是更高选择时间？

方向性假设：

- **H1**：D 的 EpisodeViolationRate 低于 A、B、C；
- **H2**：D 的 GoalRetention AUC 和 `pass^3` 高于 A、B、C，且交互长度的负向效应更小；
- **H3**：D 的恢复成功率更高、残留错误更少，C–D 用户研究中的恢复成本更低；
- **H4**：D 的感知控制和错误识别率高于 C，但候选选择时间可能更长。

## 3. 方法条件

四组必须使用同一模型版本、完整对话历史、当前规范化状态、temperature、最大输出、任务和地图条件。仅改变更新协议与守卫；不得为某一组单独增加任务提示或额外重试。

| 方法 | 更新协议 | 防护 |
| --- | --- | --- |
| A | 整个 TripDocument/UI 状态重生成 | 仅 Schema 解析；作为隔离实验基线，不进入生产入口 |
| B | 整体重生成 | 在相同 Prompt 中增加“未提及内容保持不变”，无结构守卫 |
| C | 单候选局部 Patch | 服务端路径白名单；无持久锁、不变量、版本冲突和候选确认 |
| D | 最多三候选局部 Patch | 路径、锁、不变量、版本、独立候选预览与显式提交 |

A/B 输出只能作为 JSON 数据在隔离副本中解释，禁止执行模型 HTML、JavaScript 或代码。

## 4. 实验设计

核心自动实验：6 类任务 × 4 个长度（1、5、10、20）× 4 种方法 × 5 次独立采样，共 480 个 episode/模型。至少使用一个冻结版本的真实模型；若加入第二模型，分别报告并在模型层级建模，不把两模型输出当作独立任务样本。

核心任务目标固定在首轮引入。位置敏感性作为预先声明的扩展实验，在 10/20 轮任务中比较 early/middle/near，不与核心 480 episode 混合计算主要终点。

随机化单位是 `task × length × trial`。同一单位内 A–D 共享逐字相同的 fixture 身份、初始状态和干扰轮顺序；方法执行顺序在每个 `模型 × 长度` 层内使用随机种子轮换 Williams 平衡序列，使每个方法在四个位置各出现 7–8 次并平衡一阶顺序。模型不支持 seed 时记录服务端请求 ID 和实际重复次数。

## 5. 主要终点

以下终点分别报告，禁止合成总分：

1. EpisodeViolationRate；
2. GoalRetention AUC；
3. Scope F1；
4. StaleGoalLeakage；
5. `pass^1` 与 `pass^3`；
6. 任务成功率；
7. 自动版本恢复成功率与状态残差（错误发现延迟、点击和时间成本仅属于 Study 2）。

GoalRetention AUC 只纳入从 setup 延续到 probe 的目标；在 probe 才引入的新目标不具有长程年龄，不进入该 AUC，而进入目标更新准确率、任务成功与 StaleGoalLeakage。

候选质量、延迟、成本、首次失真、生存曲线、位置敏感性和 UI 结构指标属于次要终点。

## 6. 独立真值与语义标注

每个任务在运行前包含隐藏目标账本、目标生效/退出轮次、期望状态断言和语义 rubric。模型输出不得修改评测真值。

可以由状态确定的项目使用确定性评测。开放语义目标由不知道方法条件的标注者评分；至少 20% 样本双人独立标注，报告 Cohen's κ（名义/二元）或 Krippendorff's α（有序/缺失数据）。分歧规则在正式标注前固定。

人工范围已经确认：只把 combined/probe 和真实模型执行的 setup 送盲法人工标注；distractor 的即时完成使用明确标记的结构代理，不与人工语义完成率合并。该选择已由 `open-decisions.md` 第 10 项签字生效；正式运行前仍须完成标注 pilot、冻结手册与双标/仲裁流程。

LLM Judge 只能作为敏感性分析，不能代替人工主标签；Judge Prompt、模型版本和与人工标签的一致性必须公开。

## 7. UI 失真指标

除业务状态外，正式浏览器实验记录：

- 授权子树外的规范化 UI 树编辑距离；
- 稳定 component ID 存活率和错误重绑定率；
- 非目标组件的几何位移与消失率；
- 焦点、选区、滚动位置和当前候选是否意外重置；
- 原有动作是否仍可达，以及自动可访问性违规数。

像素截图仅作错误定位，不单独作为语义正确证据。

## 8. 统计计划

- 已接受、待分析资产整体冻结的确认性方案：20 轮严格 episode task success 为唯一主终点；两个模型身份分别拟合 `success ~ method * interaction_length + execution_position + (1 | template_id) + (1 | block_id)` 的混合效应 Logistic 模型；
- 确认性比较只含 20 轮 D–A、D–B、D–C，在每个模型内作 Holm 校正；两个模型均同向且各自通过校正才称为复制成功，不把两个特定模型当作随机模型总体；
- 连续比例/AUC：适当变换后的混合模型，或任务级配对 Bootstrap 与置换检验作为稳健性分析；
- 首次失真：Kaplan–Meier 曲线和按 task 聚类的区间；
- 用户研究：C–D 配对分析，报告效应量与 95% CI；
- 主终点控制多重比较，固定 Holm 校正；次要终点明确标为探索性；
- 同时报告原始分母、失败样本和区间，不只报告 p 值。

同一模板的四个长度和多次模型采样都不是独立任务样本。跨长度描述性 Bootstrap 以 6 个任务模板为单位并在模板内保留全部长度和 trial；20 轮主终点敏感性分析只保留该长度的全部 trial。模板级双侧 sign-flip 对 64 种符号分配精确枚举，D–A/B/C 三项 task-success 比较作 Holm 校正。混合效应模型显式包含长度及方法×长度，以模板和同一 `模型×任务×长度×trial` 的四方法 block 为随机截距，并把 Williams 执行位置作为预先指定的干扰项。

正式分析脚本在解盲方法标签前冻结。数据清理只按第 9 节规则执行。

## 9. 排除、失败与缺失数据

- 模型超时、无效 JSON、被守卫拒绝均是该方法的失败，不得静默改用 Mock；
- 服务商级中断若同时影响全部条件，保留日志并按预先规则整块重跑；
- 不删除低质量、越权或零变化输出；
- 人工标注缺失单独报告，不能默认判为成功；
- 用户研究只排除预先定义的技术故障或未完成知情同意，分析同时报告意向处理与符合方案结果（若适用）。

## 10. 用户研究

自动 A–D 实验之后进行 C–D 被试内研究。参与者完成连续修改和错误恢复任务；顺序用 Latin square/平衡随机化，任务实例不重复。研究明确标为探索性：恢复成功与恢复时间是主要行为终点，四项感知控制均值是主要主观终点；Raw NASA-TLX、UMUX-Lite、适当依赖、候选信心和访谈为次要指标。

样本量由预实验方差与配对效应功效分析决定。若课程条件只能招募 12–20 人，研究明确标为探索性，不作总体人群效应的强推断。

## 11. 结论边界

- 若只有旅行领域，标题、摘要和讨论必须限定为结构化旅行编辑原型；
- 若要声称适用于一般 GenUI，至少增加一个不同状态结构和任务语义的领域；
- 规则评分不解释为成功概率；
- 结构保真不等同于事实正确、体验最优或用户满意；
- Mock 只用于回归和测量管线验证。
