决定记录：2026-11-03，研究者已接受第 1–6 项推荐方案并选择双模型复现。2026-11-06，研究者继续接受第 8–11 项推荐方案：恢复指标按 Study 1/2 拆分，用户研究采用探索性主终点与 NASA-TLX/UMUX-Lite，人工标注限定关键轮，自动实验采用 20 轮严格成功率与预注册混合效应模型；分析规范与精确 R 运行时随后单独冻结。具体模型 ID、版本日期和费用上限仍待填写，因此不会触发真实调用或整套正式实验冻结。

## 1. 非编辑行为的统一输出信封

问题：现有 A/B/C/D Prompt 主要描述文档或 Patch，但自洽、冲突和未知任务需要 `clarify/reject`，版本任务需要 `restore`，目标更新需要 `update_constraint`。

推荐：所有方法共享同一顶层 `decision = edit | clarify | reject | restore | update_constraint` 和 `message`；只有 `edit` 的负载按 A–D 不同。D 的 restore/version/lock 由真实工具执行，其他方法只能使用其预先定义的能力，不允许实验脚本替模型补答案。

## 2. Setup 轮是用户直接控制还是模型任务

问题：预算硬约束、锁和显式版本标记在当前产品中由可信 UI 控件执行，而不是自由生成 Patch。

推荐：Setup 控制操作由同一可信实验 UI 在所有方法中执行并记录，模型只处理后续 probe；但各方法是否真正执行持久守卫按条件定义。这能隔离“长期保持”，避免把自然语言路由错误混入主终点。另设次要实验评价自然语言路由。

当前自动核心任务含可靠版本恢复，但没有让真实用户发现受控错误；因此不能从 960-run 自动实验推断错误发现时间或点击恢复成本。

## 10. 人工语义标注范围

8040 次模型调用全部逐轮人工标注不符合课程人力。当前实现的推荐范围是：combined/probe 与真实模型执行的 setup 进行盲法人工语义/候选标注；distractor 只计算确定性 Scope、约束、行为信封和 ID 保持，并显式标为结构代理。最多为 1080 个语义样本 + 150 个候选批次，共 1230 个唯一样本；语义与候选各至少 20% 双标时最低需 1476 次样本分配，仲裁另计。

- [x] 接受关键轮人工标注范围

## 11. 自动实验主终点与混合效应模型

推荐：唯一确认性主终点固定为 20 轮条件的严格 episode task success。两个冻结模型身份分别拟合 Logistic 混合模型：`success ~ method * interaction_length + execution_position + (1 | template_id) + (1 | block_id)`；确认性比较只含 D–A、D–B、D–C，并在每个模型内作 Holm 校正。GoalRetention AUC、未授权变化、首次失真及 pooled model 分析均为次要或敏感性分析。若主模型分离、不收敛或奇异，报告诊断失败，不在看过结果后更换主终点或把敏感性分析升级为主分析。

该方案已实现为 `analysis/model-spec.json`、正式数据设计审计器和 R 分析脚本。第 11 项签字后，分析规范已标记为 `frozen`，R 与包版本已通过合成合同并锁定为 `frozen-tested`；若后续修改，必须记录协议修订并重新生成哈希证据。
